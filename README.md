# Kafé Maravilla — web

Landing de Kafé Maravilla (café 100% arábica lavado de Jipijapa, Manabí) con pedidos por WhatsApp.

- Sitio estático: `index.html`, `styles.css`, `app.js` (carrito y pedido), `anim.js` (animaciones GSAP).
- Número de WhatsApp y precio: `CONFIG` al inicio de `app.js`.
- Logo animado por capas en `assets/img/logo/`.

Probar en local:

```bash
python -m http.server 5391
```
